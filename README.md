## 🕹️ Sobre o Projeto

Este repositório guarda o código-fonte do meu portfólio pessoal (**Sant v7**). Mais do que uma vitrine de projetos, esta aplicação funciona como um **laboratório vivo de experiências**, onde testo novas bibliotecas de animação, conceitos avançados de UI/UX, componentes dinâmicos e integrações em tempo real.

O projeto foi construído do zero, unindo o gosto de **pixel art** com uma **estética tecnológica, futurista e cyberpunk**, oferecendo uma navegação fluida, interativa e cheia de personalidade. 👑☕

## 🛠️ Tech Stack & Ferramentas

### 🎨 Front-End & Estilização
- **React** (Componentização limpa e modular)
- **TypeScript** (Tipagem estática e segurança)
- **CSS Modules / SCSS / Tailwind CSS** (Estilização isolada e responsiva)

### 🎬 Animações & Interatividade
- **GSAP (GreenSock)** & **ScrollTrigger** (Animações complexas de scroll e micro-interações)
- **Lenis Scroll** (Smooth scroll ultra fluido)
- **Anime.js** (Efeitos visuais e transições de elementos)

### 🔌 APIs & Consumo de Dados
- **GitHub REST API** (Integração em tempo real para exibição automática de repositórios, commits e métricas do perfil)

### 📐 Design & Prototipagem
- **Figma** (Prototipagem de alta fidelidade, design system, UI/UX design e assets pixel-art)

---

## 🎮 Principais Funcionalidades

- **Laboratório Experimental:** Componentes criados para testar animações complexas, manipulação de DOM e performance.
- **Dynamic GitHub Feed:** Consumo da API do GitHub para trazer dados atualizados de repositórios e atividade.
- **Navegação Imersiva:** Scroll suave com Lenis alinhado a gatilhos visuais via GSAP.
- **Interface Pixel-Art & HUD:** Estética inspirada em retrogames e interfaces cyberpunk (com estatísticas no estilo card de jogador).
- **Design Responsivo:** Adaptado para todos os tamanhos de tela com foco em Mobile-First Workflow.
